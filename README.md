# FT-AI-4 Presentations

A reveal.js + React + TypeScript SPA for online-course lectures, published on GitHub Pages.

The app is not scaffolded yet. Agent context lives in `memory-bank/` (read that, not only this README).

## Commands for agents

- **initialize memory bank** — create or repair `memory-bank/`
- **update memory bank** — refresh all bank files from current work
- **follow your custom instructions** — resume from `memory-bank/activeContext.md`

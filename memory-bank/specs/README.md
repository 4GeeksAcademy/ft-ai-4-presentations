# Specs

Feature and delivery specs for FT-AI-4 Presentations. Core product context stays in the Memory Bank root; this folder holds **plans and acceptance criteria** agents execute against.

**Naming:** kebab-case only (`dev-plan.md`, `multiplex-ux.md`, …).

| Spec | Purpose |
| --- | --- |
| [dev-plan.md](dev-plan.md) | Phased build order and exit criteria (source of delivery truth) |

Add new specs as `specs/<feature>.md` when a slice needs more detail than the dev plan (e.g. theme, lecture registry, multiplex UX). Link them from the table above and from `dev-plan.md`.
